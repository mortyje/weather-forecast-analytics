
# Источники погодных данных

## Прогнозы погоды

Источник: Open-Meteo Forecast API.

Документация: https://open-meteo.com/en/docs

Параметры сбора:
- Периодичность: каждые 3 часа.
- Горизонт прогнозирования: 7 дней.
- Детализация: 1 час.
- Часовой пояс: UTC.
- Количество городов на первом этапе: 5.

Собираемые показатели:
- `temperature_2m` — температура воздуха, °C.
- `relative_humidity_2m` — относительная влажность, %.
- `precipitation` — количество осадков, мм за предшествующий час.
- `wind_speed_10m` — скорость ветра, км/ч.

Каждый успешный сбор сохраняется как отдельный снимок прогноза.

Для каждого снимка необходимо фиксировать время получения, источник, координаты, параметры запроса и исходный JSON-ответ.

Время получения прогноза не считается временем инициализации погодной модели.

## Фактические наблюдения

Источник: Meteostat.

Документация: https://dev.meteostat.net/

Используются почасовые наблюдения метеостанций.

При работе через JSON API необходимо указывать `model=false`, чтобы исключить подстановку модельных данных вместо отсутствующих наблюдений.

Планируемые показатели:
- Температура воздуха.
- Относительная влажность.
- Количество осадков.
- Скорость ветра.

Сбор выполняется ежедневно с повторной загрузкой недавнего периода для учёта запаздывающих наблюдений и исправлений.

## Сопоставление данных

Прогнозы и фактические наблюдения сопоставляются по:
- Метеостанции и соответствующей точке прогноза.
- Целевому времени прогноза.
- Погодному показателю.

При сравнении учитываются единицы измерения, временные интервалы и отсутствие фактических данных.

Пропущенные наблюдения не заменяются прогнозными значениями.

## Историчность

Снимки прогнозов сохраняются без перезаписи предыдущих значений.

Повторное выполнение одной и той же задачи сбора не должно создавать дубликаты.

Сохраняются исходные ответы источников, чтобы изменения в обработке можно было воспроизвести без повторного запроса к API.
